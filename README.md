# 网格点位可视化工具

将测试数据表格转换为网格点位可视化图表，支持标注每个点位的成功/失败次数、备注，并提供**网格坐标图、热力图、方块视图**三种图表，以及点位成功率明细与一键报告总结。基于 **PySide6** 桌面 GUI，支持 Windows / macOS。

## 功能特性

### 顶部菜单栏

窗口顶部采用三个下拉菜单，统一管理原有分散的按钮：

- **📥 导入**：浏览文件… / 拖拽导入… / 粘贴导入…
- **⚙️ 设置**：画布设置…
- **📊 视图**：网格坐标图 / 热力图 / 方块视图（三项可勾选，当前视图高亮）

### 数据导入（三种方式）

- 拖拽表格文件到窗口左侧区域，支持 `.xlsx` / `.xls` / `.csv`（CSV 编码自动识别：UTF-8-SIG / UTF-8 / GB18030 / GBK / Latin-1）
- 通过 📥 导入 → 浏览文件… 选择文件
- 粘贴区直接粘贴表格内容导入，自动识别多种格式：
  - 常规 Tab / 逗号 / 空格分隔格式（Excel/WPS 复制粘贴，含框选多行复制；表头 4 列 + 数据行 3/4 列混合时自动补空备注列对齐，不再报列数不匹配）
  - 竖排堆叠格式（点位/成功次数/失败次数三列纵向排列，表头连续式与三段式两种形态）
  - **单行点位模式**：`点位 成功次数 失败次数 备注 A6 3 0 A7 3 0 ...`，按"字母+数字"点位字段自动分行，支持空备注与长备注（含空格）混合；数据无表头时自动补标准表头
  - 第 4 列备注自动识别（列名支持 备注/note/remark/comment/说明，无法识别时取第 4 列位次）
- 自动识别中英文列名（点位/point、成功次数/success、失败次数/fail），无法识别时按位置取值

### 画布设置（⚙️ 设置 → 画布设置…）

- 行数 3–26（A–Z）、列数 3–50 可调
- 画布宽（6–40 英寸）/ 高（4–30 英寸）可调
- 中心点随行列数自动重算（奇数尺寸落在具体格，如 7×17 → D9；偶数尺寸显示两行/两列之间）
- **中心线**：不显示（默认）/ 断断续续的虚线 / 实心线，控制中心十字线
- "显示全部点位"开关：一键在灰色未测试点位旁标注名称
- **还原默认设置**：一键恢复为默认 7 行 × 17 列、16 × 9 英寸、不显示中心线

### 数据表（左侧）

- 四列：点位 / 成功次数 / 失败次数 / 备注（表头列名不可编辑）
- **新建点位行下拉**（左侧主按钮，默认首选自动插入）：
  - **自动插入画布点位**：按当前网格行数 × 列数生成全部点位（如 7×17 → A1..A17、B1..B17 … G17），自然升序（A2 < A10）填入点位列；点位列已有内容时先确认再整列覆盖
  - 新建点位行：新建空白数据表
  - 添加点位行…：批量添加多行（对话框输入 1–100 行）
- 单元格编辑支持：
  - `Ctrl+C` / `Ctrl+V` 复制粘贴（含整表格式复制）
  - `Ctrl+Z` 撤销（最多 50 步）
  - 选中单元格文字以蓝色高亮显示
  - 点位名重复提醒：输入与表内已有点位相同的名称时弹出提示
- **右键一键标注**：点位单元格右键选择"标注此点位（黄色圈注）"，标注后单元格背景填充黄色；对应图表中该点位生成黄色空心圈注，再次右键可取消标注
- **高亮设置**下拉：🅰 文字颜色 / ⬜ 背景颜色 / 🧹 清除所有高亮显示（按点位名绑定，排序后跟随）
- **🖌 格式刷**：点击激活后读取当前选中单元格的文字/背景颜色，连续点击目标单元格应用，再点按钮取消
- 排序：字段下拉（原始顺序 / 点位 / 成功次数 / 失败次数 / 点位成功率）+ 排序方向下拉（升序 / 降序）；点位按自然排序，数值相同再按点位自然序
- **导出数据**下拉：⧉ 复制表格（HTML+Tab 双格式，可直接粘贴到 Excel/WPS/飞书）/ 💾 导出 CSV（UTF-8 BOM，Excel 直接打开不乱码）
- ⛶ 全屏显示：全屏查看点位成功率明细，可导出

### 图表预览（右侧）

通过 📊 视图菜单在三种图表间切换，图表以位图渲染（Agg 后端，规避 matplotlib 与 PySide6 的 Qt 兼容问题）。

**图表标题**

- 顶部「图表标题:」输入框，**默认留空**；输入内容实时应用于全部三种图表（预览/全屏/保存/复制）
- 输入框留空时，网格图与方块图不显示标题；热力图不显示总标题
- 有标题时：网格图标题居中、与左右统计框同一水平线；方块图 suptitle 紧靠方块；热力图总标题相对两个面板的整体中心居中

**网格坐标图**

- 左上角统计框：总点位 / 成功点位 / 失败点位；右上角统计框：成功次数 / 失败次数 / 成功率（位置固定，标题有无都不漂移）
- 点位配色（测试点带黑色描边）：
  - 仅失败（成功=0、失败>0）→ 红色 `#E53935`
  - 仅成功（成功>0、失败=0）→ 绿色 `#2E7D32`
  - 成败兼有（成功、失败都>0）→ 浅绿 `#C8E6C9`
  - 成功=失败=0 或未测试 → 灰色 `#A9A9A9`
- 被标注点位显示黄色空心圈
- 点位下方两行文字：点位名称 + `(成功次数 / 失败次数)`，成功次数绿色、失败次数红色（失败为 0 不标红）

**热力图**

- 成功（Blues 蓝色系）/ 失败（Reds 红色系）双面板并排，各配**竖直深度刻度尺**（位于面板右侧）
- 圆角方块、保持正方形；行列标签与方块视图一致（字号 20、加粗、灰色 `#888888`，靠近方块）
- 每格标注"点位\n(次数)"两行文字，次数为 0 留空；文字颜色随格子深浅自动切换黑/白
- 面板标题为「成功次数热力图」「失败次数热力图」

**方块视图**

- 圆角方块（`FancyBboxPatch`），方块间留白色间隙，保持正方形
- 配色（按成功次数）：
  - 未覆盖（成功=失败=0）→ 灰色 `#D0D0D0`
  - 成功=0、失败>0 → 红色 `#E53935`
  - 成功=1 → 黄色 `#FFC107`
  - 成功≥2 → 绿色热力色系，由浅到深三档 `#b2e0ac` / `#4bb062` / `#006428`，成功次数越多颜色越深
- 方块内数字字号 16，采用圆滑字体（Arial Rounded MT Bold，回退微软雅黑）
- 数字颜色：红格或失败次数为 0 时白色，其余黑色
- 采样点：仅被标注点位，在方块右上方显示白环 + 蓝心（`#4169E1`）双圆点
- 行列标签字号 20、加粗、灰色 `#888888`，靠近方块；外框线隐藏
- 图内底部图例：0次全失败 / 成功1次 / 三个绿点 + 成功≥2次 / 采样点，按真实渲染宽度精确居中

**保存图片 / 预览对比**

- 保存图片下拉：复制到剪贴板 / 另存为（默认文件名自动同步标题，方块视图加"_方块视图"、热力图加"_热力图"后缀，非法字符自动清理）
- 预览对比下拉：
  - ⛶ 全屏预览：全屏查看当前图表，Esc 退出
  - 🖼 图片对比：选择 2–4 张图片拼接（2 张左右并排、3–4 张按 2 列网格；支持 PNG / JPG / JPEG），结果在对话框中预览，支持全屏 / 复制 / 另存为

### 报告总结（一键输出）

- 表格（左）+ 网格坐标图（右）左右拼接，200dpi 高清渲染
- 表格左上角同步显示图表标题；备注列长文本自动换行，行高自适应
- 表格内文字/背景高亮同步到报告
- 点击后弹出：⛶ 全屏预览 / ⧉ 复制到剪贴板 / 💾 另存为

### 底部图例栏与状态栏

- 主界面底部图例栏按视图切换：网格坐标图显示网格图例（仅失败/仅成功/成败兼有/特殊标注点位），方块视图显示方块图例（靠左排列），热力图隐藏
- 右下角显示「当前：网格坐标图 / 热力图 / 方块视图」，切换视图实时同步
- 主窗口状态栏消息（左侧）显示导入、保存等操作提示

### 跨平台

- 中文字体自动配置：Windows 用黑体/微软雅黑，macOS 用苹方/冬青黑体

## 环境要求

- **Python 3.12+**（锁定依赖的最低要求：numpy 2.5.x 需 ≥3.12、matplotlib 3.11.x 需 ≥3.11、PySide6 6.11.x 需 ≥3.10；已实测兼容 3.12 / 3.13）
- Windows 或 macOS（中文字体自动配置）
- 依赖包版本见 `requirements.txt`（已锁定）

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

> 推荐使用虚拟环境：`python -m venv .venv` 后激活，再安装依赖。

### 2. 启动程序

在项目根目录下执行：

```bash
python src/grid_visualization_gui.py
```

### 3. 导入数据并查看

1. 通过 📥 导入菜单，或用「自动插入画布点位」快速生成网格点位
2. 左侧数据表确认数据，可编辑、标注、加行、排序、导出
3. 通过 📊 视图菜单切换网格坐标图 / 热力图 / 方块视图
4. 需要时编辑图表标题、保存图片、预览对比或生成报告总结

## 数据格式说明

表格需包含三列或四列：

| 点位 | 成功次数 | 失败次数 | 备注 |
|------|----------|----------|------|
| D9   | 2        | 0        | 成功 |
| C8   | 2        | 1        | 对不准 |
| A6   | 1        | 1        | 夹太浅中途掉下来了，放不下 |

> 备注列可选；列名支持中英文：`点位/point`、`成功次数/success`、`失败次数/fail`、`备注/note/remark/comment/说明`；无法识别时按列位次取值。

**粘贴竖排格式**（自动识别，两种形态均可）：

形态一（表头连续三行，数据按 点位/成功/失败 三行一组循环）：

```
点位
成功次数
失败次数
A6
0
3
A7
3
0
```

形态二（三段式，各段带表头）：

```
点位
A6
A7
成功次数
0
3
失败次数
3
0
```

**粘贴单行点位模式**（框选复制到单行输入框的场景，自动识别）：

```
点位 成功次数 失败次数 备注 A6 3 0 A7 3 0 A11 0 3 夹太浅中途掉下来了，放不下 B6 2 1 对不准
```

> 按"字母+数字"点位字段自动分行；空备注、长备注（含空格）均可正确对位；无表头时自动补表头。

**粘贴竖排单字段格式**（Excel/飞书复制成"每行一个单元格"，自动识别）：

```
点位	成功次数	失败次数	备注
A6
3
0
A7
3
0
```

> 表头一行 + 数据每行一个单元格；自动按 点位/成功/失败次数[/备注] 纵向循环重建；
> 表头 4 列而数据缺备注值时自动补空备注列；无表头时按数据字段数自动生成表头；
> 数据列数与表头不匹配时给出中文提示而非程序报错。

## 打包发布

**Windows 免安装包**
- 在项目根目录执行：`pyinstaller --noconfirm --windowed --icon img/logo.ico --name GridVisualization src/grid_visualization_gui.py`

**macOS 应用包**

## 图表标注说明

**网格坐标图**每个测试点位下方显示两行文字：

```
  点位名称
 (成功次数 / 失败次数)
```

| 元素 | 含义 |
|------|------|
| 绿色数字 | 成功次数 |
| 红色数字 | 失败次数（失败 > 0 时加粗） |
| 红色圆点 | 仅失败 |
| 绿色圆点 | 仅成功 |
| 浅绿圆点 | 成败兼有 |
| 灰色圆点 | 未测试 / 无有效结果 |
| 黄色空心圈 | 特殊标注点位 |

**方块视图**通过方块颜色与内部数字表达成功次数，图内底部附图例说明；采样点为方块右上方的白环蓝心圆点。

**热力图**每格标注"点位\n(次数)"，次数为 0 留空，右侧竖直刻度尺表示数值大小。

## 常见问题

**Q: 拖拽文件没有反应？**
A: 确保文件路径不含特殊字符，也可使用 📥 导入 → 浏览文件…。

**Q: 修改了 Excel 文件但图片没有更新？**
A: 修改数据后需要重新导入文件；Excel 文件正在编辑时请先保存并关闭。

**Q: 中文显示为方框或乱码？**
A: 程序会自动加载系统中文字体（Windows: SimHei/微软雅黑，macOS: 苹方等）。如仍有问题，请确保系统已安装中文字体。

**Q: 提示找不到模块？**
A: 运行 `pip install -r requirements.txt` 安装所有依赖（版本已锁定）。请勿混用系统 Python 与虚拟环境中的依赖，推荐统一使用项目 venv。

**Q: 表格列名不是中文怎么办？**
A: 程序支持英文列名自动识别：`point/点位`、`success/成功次数`、`fail/失败次数`、`note/remark/comment/说明/备注`。无法识别时按位置取前 3 列（第 4 列按备注处理）。

**Q: 竖排粘贴的数据识别不出来？**
A: 确认"点位 / 成功次数 / 失败次数"与数据行严格对应；任一数值行含非整数会导致识别失败，请改用 Tab / 逗号分隔格式或单行点位模式。

**Q: 全屏图表弹出后闪退 / 报错？**
A: 全屏图表采用位图渲染，不依赖 matplotlib 的 Qt 窗口管理。若仍出现依赖相关报错，请用 `pip install -r requirements.txt` 统一依赖版本后重试。

**Q: 图片如何保存？**
A: 图表预览区"保存图片"下拉：复制到剪贴板直接复制当前图表；另存为弹出对话框，默认文件名同步图表标题（非法字符自动清理），并按视图追加"_热力图"/"_方块视图"后缀。
