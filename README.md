# 网格点位可视化工具

将测试数据表格转换为网格坐标可视化图表，支持标注每个点位的成功/失败次数、备注，并提供热力图、点位成功率明细与一键报告总结。基于 **PySide6** 桌面 GUI，支持 Windows / macOS。

## 功能特性

**数据导入（三种方式）**
- 拖拽表格文件到窗口左侧区域，支持 `.xlsx` / `.xls` / `.csv`（CSV 编码自动识别：UTF-8-SIG / UTF-8 / GB18030 / GBK / Latin-1）
- 点击"浏览文件..."按钮选择文件
- 右侧粘贴区直接粘贴表格内容导入，自动识别多种格式：
  - 常规 Tab / 逗号 / 空格分隔格式（Excel/WPS 复制粘贴，含框选多行复制；表头 4 列 + 数据行 3/4 列混合时自动补空备注列对齐，不再报列数不匹配）
  - 竖排堆叠格式（点位/成功次数/失败次数三列纵向排列，表头连续式与三段式两种形态）
  - **单行点位模式**：`点位 成功次数 失败次数 备注 A6 3 0 A7 3 0 ...`，按"字母+数字"点位字段自动分行，支持空备注与长备注（含空格）混合；数据无表头时自动补标准表头
  - 第 4 列备注自动识别（列名支持 备注/note/remark/comment/说明，无法识别时取第 4 列位次）
- 自动识别中英文列名（点位/point、成功次数/success、失败次数/fail），无法识别时按位置取值

**画布设置（网格可配置）**
- 行数 3–26（A–Z）、列数 3–50 可调
- 画布宽（6–40 英寸）/ 高（4–30 英寸）可调
- 中心点随行列数自动重算（奇数尺寸落在具体格，如 7×17 → D9；偶数尺寸显示两行/两列之间）
- "显示全部点位"开关（默认开启）：一键在灰色未测试点位旁标注名称

**数据表（左侧表格，可创建与编辑）**
- 四列：点位 / 成功次数 / 失败次数 / 备注（表头"点位"等列名不可编辑）
- 新建数据表默认 20 行；"添加点位行"按钮一次可批量添加多行（弹出对话框输入行数，1–100），无需逐行添加
- 单元格编辑支持：
  - `Ctrl+C` / `Ctrl+V` 复制粘贴（含整表格式复制）
  - `Ctrl+Z` 撤销（最多 50 步）
  - 选中单元格文字以蓝色高亮显示
  - 点位名重复提醒：输入与表内已有点位相同的名称时弹出"与上述单元行点位名重复，重复输入会导致网格图生成结果覆盖"
- "⧉ 复制表格"：一键复制整表（含列名与单元格格式），可直接粘贴到 Excel/WPS/飞书（标准 HTML+Tab 纯文本双格式）
- "🎨 高亮显示设置"下拉：🅰 文字颜色 / ⬜ 背景颜色 / 🧹 清除所有高亮显示（按点位名绑定，排序后跟随）
- "🖌 格式刷"：点击激活后读取当前选中单元格的文字/背景颜色，连续点击目标单元格应用，再点按钮取消

**数据预览（左侧表格）**
- 四列：点位 / 成功次数 / 失败次数 / 备注；另有点位成功率（0/0 显示 —）
- 排序下拉：原始顺序 / 点位 / 成功次数 / 失败次数 / 点位成功率，配合互斥的升序/降序按钮；点位按自然排序（A2 < A10），数值相同再按点位自然序，默认恢复原始排列
- "⛶ 全屏显示"：全屏查看点位成功率明细（5 列，沿用当前排序），可导出
- "导出数据"：按当前排序导出 CSV（含备注列，UTF-8 BOM，Excel 直接打开不乱码）

**图表预览（右侧）**
- 网格坐标图 / 热力图一键切换
- 网格坐标图：
  - 可编辑标题，应用于全局显示（预览/全屏/报告总结）
  - 左上角统计框：总点位 / 成功点位 / 失败点位
  - 右上角统计框：成功次数 / 失败次数 / 成功率（与标题同一水平线）
  - 蓝色圆点 = 全部成功，橙色圆点 = 存在失败，灰色圆点 = 未测试
  - 点位下方两行文字：点位名称 + (成功次数 / 失败次数)，失败次数为 0 不标红
- 热力图：成功/失败双图并排，每格标注"点位\n(次数)"两行文字（次数为 0 留空），白色分割线增强分辨
- "保存图片"下拉：⧉ 复制到剪贴板 / 💾 另存为（另存为默认文件名自动同步为网格坐标图标题，热力图加"_热力图"后缀，标题中的非法字符自动清理）
- "预览对比"下拉：⛶ 全屏预览（全屏查看当前图表，Esc 退出；位图渲染兼容不同 matplotlib/PySide6 组合）/ 🖼 图片对比（选择 2-4 张图片拼接：2 张左右并排、3-4 张按 2 列网格；支持 PNG / JPG / JPEG，拼接结果在正式对话框中预览，支持 ⛶ 全屏预览 / ⧉ 复制到剪贴板 / 💾 另存为，全屏预览可「⬅ 返回对比」回到上一级）

**🖼 报告总结（一键输出）**
- 表格（左）+ 网格坐标图（右）左右拼接输出，200dpi 高清渲染，可直接对比
- 表格左上角同步显示网格坐标图标题
- 表格备注列长文本自动换行，行高按文本行数自适应
- 表格内的文字/背景颜色高亮同步到报告
- 点击后弹三个功能项：⛶ 全屏预览（保持比例缩放整图）/ ⧉ 复制到剪贴板 / 💾 另存为

**状态栏（主界面左下角）**
- 总点位 | 成功点位 | 失败点位 | 成功次数 | 失败次数 | 成功率

**跨平台**
- 中文字体自动配置：Windows 用黑体/微软雅黑，macOS 用苹方/冬青黑体

## 环境要求

- **Python 3.12+**（锁定依赖的最低要求：numpy 2.5.x 需 ≥3.12、matplotlib 3.11.x 需 ≥3.11、PySide6 6.11.x 需 ≥3.10；已实测兼容 3.12 / 3.13）
- Windows 或 macOS（中文字体自动配置）
- 依赖包版本见 `requirements.txt`（已锁定）

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

> 推荐使用虚拟环境：`python -m venv .venv` 后激活，再安装依赖。

### 2. 启动程序

在项目根目录（`D:\GV_Tool`）下执行：

```bash
python src/grid_visualization_gui.py
```

### 3. 导入数据并查看

1. 拖拽 / 选择 / 粘贴导入数据表格
2. 左侧数据表确认数据与点位成功率，可编辑、加行、复制或导出
3. 右侧切换"网格坐标图"或"热力图"查看
4. 需要时编辑标题、保存图片、预览对比或导出数据
5. 点击"🖼 报告总结"生成表格+网格图拼接报告

## 数据格式说明

表格需包含三列或四列：

| 点位 | 成功次数 | 失败次数 | 备注 |
|------|----------|----------|------|
| D9   | 2        | 0        | 成功 |
| C8   | 2        | 1        | 对不准 |
| A6   | 1        | 1        | 夹太浅中途掉下来了，放不下 |

> 备注列可选；列名支持中英文：`点位/point`、`成功次数/success`、`失败次数/fail`、`备注/note/remark/comment/说明`；无法识别时按列位次取值。

**粘贴竖排格式**（自动识别，两种形态均可）：

形态一（表头连续三行，数据按 点位/成功/失败 三行一组循环）：

```
点位
成功次数
失败次数
A6
0
3
A7
3
0
```

形态二（三段式，各段带表头）：

```
点位
A6
A7
成功次数
0
3
失败次数
3
0
```

**粘贴单行点位模式**（框选复制到单行输入框的场景，自动识别）：

```
点位 成功次数 失败次数 备注 A6 3 0 A7 3 0 A11 0 3 夹太浅中途掉下来了，放不下 B6 2 1 对不准
```

> 按"字母+数字"点位字段自动分行；空备注、长备注（含空格）均可正确对位；无表头时自动补表头。

**粘贴竖排单字段格式**（Excel/飞书复制成"每行一个单元格"，自动识别）：

\点位	成功次数	失败次数	备注
A6
3
0
A7
3
0
A8
3
0
\
> 表头一行 + 数据每行一个单元格；自动按 点位/成功次数/失败次数[/备注] 纵向循环重建；
> 表头 4 列而数据缺备注值时自动补空备注列；无表头时按数据字段数自动生成表头；
> 数据列数与表头不匹配时给出中文提示而非程序报错。

## 打包发布

**Windows 免安装包**
- 在项目根目录执行：`pyinstaller --noconfirm --windowed --icon img/logo.ico --name GridVisualization src/grid_visualization_gui.py`
- PySide6 由官方 hook 自动收集；运行时依赖（PySide6 / matplotlib / seaborn / pandas / numpy / openpyxl / xlrd / Pillow）需全部随包收集
- 打包依赖见 `requirements.txt` 底部注释（日常运行不需要安装）

**macOS 应用包**
- PyInstaller **不能跨平台打包**，`.app` 必须在 Mac 上构建：先在 Mac 上安装依赖并执行同样的 pyinstaller 命令（`--windowed --icon img/logo.ico src/grid_visualization_gui.py`），再将 `dist/` 下的 `.app` 拖入"应用程序"或自行打包成 dmg
- 说明：本仓库当前仅含源码与图标，不含历史发布包（`网格测试点位可视化-Windows.zip`）与 macOS 打包脚本（`macos-build/`），如需旧版发布物请从归档或发布记录中获取

## 图表标注说明

**网格坐标图**每个测试点位下方显示两行文字：

```
  点位名称
 (成功次数 / 失败次数)
```

| 元素 | 含义 |
|------|------|
| 绿色数字 | 成功次数 |
| 红色数字 | 失败次数（失败 > 0 时加粗） |
| 蓝色圆点 | 全部成功 |
| 橙色圆点 | 存在失败 |
| 灰色圆点 | 未测试 |

**热力图**每格标注两行："点位" + "(次数)"，次数为 0 的格子留空；白色分割线分隔格子。

## 常见问题

**Q: 拖拽文件没有反应？**
A: 确保文件路径不含特殊字符，也可使用"浏览文件..."按钮选择。

**Q: 修改了 Excel 文件但图片没有更新？**
A: 修改数据后需要重新导入文件；Excel 文件正在编辑时请先保存并关闭。

**Q: 中文显示为方框或乱码？**
A: 程序会自动加载系统中文字体（Windows: SimHei/微软雅黑，macOS: 苹方等）。如仍有问题，请确保系统已安装中文字体。

**Q: 提示找不到模块？**
A: 运行 `pip install -r requirements.txt` 安装所有依赖（版本已锁定）。请勿混用系统 Python 与虚拟环境中的依赖，推荐统一使用项目 venv。

**Q: 表格列名不是中文怎么办？**
A: 程序支持英文列名自动识别：`point/点位`、`success/成功次数`、`fail/失败次数`、`note/remark/comment/说明/备注`。无法识别时会按位置取前 3 列（第 4 列按备注处理）。

**Q: 竖排粘贴的数据识别不出来？**
A: 确认三行表头"点位 / 成功次数 / 失败次数"与数据行严格对应；任一数值行含非整数会导致识别失败，请改用 Tab / 逗号分隔格式或单行点位模式。

**Q: 全屏图表弹出后闪退 / 报错？**
A: 全屏图表已改为位图渲染，不依赖 matplotlib 的 Qt 窗口管理。若仍出现依赖相关报错，请用 `pip install -r requirements.txt` 统一依赖版本后重试。

**Q: 图片如何保存？**
A: 图表预览区"保存图片"下拉："复制到剪贴板"直接复制当前图表；"另存为"弹出保存对话框，默认文件名自动同步为网格坐标图标题（非法字符自动清理），热力图加"_热力图"后缀。
